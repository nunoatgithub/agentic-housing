# House growth viewer

Animates how the houses grew, step by step: the incremental agent against the all-at-once agent,
with the four quality scores shown as changes against the original house.

- `index.html`: the main page. Pick a run (1, 2, 3, 4 or 5), a house, an agent chain and a mode
  (Incremental / All-at-once / Both), then play or scrub. The "Score evolution" tab on the right edge opens,
  level with it, a see-through panel over the screen with the four score charts in a 2x2 grid. In each chart the steps
  run left to right and the change against the seed house up and down (up = better; the dashed line is the seed
  house). Every agent of every chain of the house has its own colour and a thin line; the chain playing is drawn on
  top and grows as the steps play. At the left of each chart the agents are listed from the best score to the worst,
  with their current value (the final one for those not playing). Each chart's vertical scale fits the chain playing,
  so other chains' wilder swings can run off it.
  At the right of the charts, a horizontal bar per agent gives the share of the rooms of the house a call started
  from that its own house no longer has (same cell and type gone: removed or replaced), so rooms built by an earlier
  step count too; a bar shows the largest share of any call so far and never shrinks as the steps play.
- `house.html` + `sketch.js`: the three.js house drawing, embedded by `index.html`.
  It also works alone; `?data=<file>` picks the data file (default `data.json`).
- `data_run1.json` (run 1, `runs_100_rooms`), `data.json` (run 2, `runs_100_rooms_no_hallways`), `data_run3.json`
  (run 3, `runs_100_rooms_refactor`), `data_run4.json` (run 4, `runs_100_rooms_refactor_cost`) and `data_run5.json`
  (run 5, `runs_100_rooms_cost`): generated by `build_data.py`, from the repo root. A house with no agent call yet is
  left out, so a run in progress shows its houses as their chains are run:

      python viewer/build_data.py runs_100_rooms_no_hallways -o viewer/data.json
      python viewer/build_data.py runs_100_rooms -o viewer/data_run1.json
      python viewer/build_data.py runs_100_rooms_refactor -o viewer/data_run3.json
      python viewer/build_data.py runs_100_rooms_refactor_cost -o viewer/data_run4.json
      python viewer/build_data.py runs_100_rooms_cost -o viewer/data_run5.json

Serve the folder over HTTP (modules and `fetch` need it), e.g. `python -m http.server 8777`
inside `viewer/`, then open `http://localhost:8777/`. three.js r160 is vendored in `vendor/`.
